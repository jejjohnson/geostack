pipekit-evaluate — every score tagged, in one report
Wrap any metric as a tagged scorer, score one prediction or a whole benchmark ladder, and read one content-hashed report: cut it by any tag, diff it against a baseline, identify it by its hash.
supplywhat you bring
a prediction, a reference
\hat{\mathbf{y}} and \mathbf{y}_\text{ref} in any carrier the scorers take: an array, an xarray Dataset, or an Estimate with a posterior
your metrics
any callable from (prediction, reference) to a result, such as an xrops.metrics operator
or a benchmark task
a Task (prior, simulator, observation operator, datasets) and one Estimator per rung and complexity step
what was run
model_ref, dataset_ref and a config, recorded on the report and in its hash
one reportevery value, tagged
{\mathcal{R} = \left\{ \left( k, m, s_{k,m}, \tau_k \right) : k \in \mathcal{K},\ m \in \mathcal{M}_k \right\}}
value m of scorer k, the prediction against the reference
s_{k,m}(\hat{\mathbf{y}}, \mathbf{y}_\text{ref}) \in \mathbb{R}
the scorer's tags: the unit it scores, its lens, the stages it may run at
\tau_k = (u_k, \ell_k, \mathcal{S}_k)
in a benchmark: cell c = (L, r, j), scored against reference \rho
v_{c,\rho,k,m} = s_{k,m}(q_c, \mathbf{y}_\rho)
Each entry is keyed cell:reference:scorer.metric. The hash covers the entries, model_ref, dataset_ref and the config, but not the entries' order or the timestamp.
