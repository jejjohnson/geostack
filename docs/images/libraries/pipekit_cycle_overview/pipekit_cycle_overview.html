pipekit-cycle — forecast, observe, analyse, on a clock
You bring the model, the observation operator and the analysis; pipekit-cycle owns the loop around them: the clock, which observations belong to which step, and resuming where a run stopped.
supplyseams and data
forward model f
any object with step(state, dt), dt and state_signature: a ForwardModel
observation operator h
__call__(state) and linearize(state), or a ready-made one from components
analysis a
one call, an AnalysisStep: an EnKF, a 3D-Var, a particle filter, from filterax, vardax or your own
observations \mathbf{y}_t and \boldsymbol{\Sigma}_\varepsilon
an operator called with the step index, and the error covariance on DAState
one cyclerepeated T times
\mathbf{x}_{t \mid t} = a\left(f(\mathbf{x}_{t-1 \mid t-1}), \mathbf{y}_t; h, \boldsymbol{\Sigma}_\varepsilon\right)
the state-space model behind the three seams
\mathbf{x}_t = f(\mathbf{x}_{t-1}) + \boldsymbol{\eta}_t, \quad \mathbf{y}_t = h(\mathbf{x}_t) + \boldsymbol{\varepsilon}_t
every cycle is a stateful operator
(\mathbf{x}_T, s_T) = \text{cycle}(\mathbf{x}_0, s_0)
The carry state s holds the clock, the cycle count and \boldsymbol{\Sigma}_\varepsilon, so with obs_clock="state" two calls of five cycles give the same analysis as one call of ten.
