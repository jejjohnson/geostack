pipekit — one pipeline, seven packages
Every step is an Operator, and every way of combining steps returns one, so a whole workflow is one composition. Each package supplies operators of one kind, and all of them chain with |.

p = o_K \circ \cdots \circ o_2 \circ o_1
each step, from one set of carriers to the next
o_k : \mathcal{X}_{k-1} \to \mathcal{X}_k
a step that carries state, such as a cycle
(x_t, s_t) = o(x_{t-1}, s_{t-1})
a name for its configuration, the content hash
h(p) = \mathrm{SHA256}(\mathrm{json}(s_p))
Because p is an operator, it can be called, inspected before it runs, mapped over many inputs, hashed and written to JSON like any one of its steps. Two pipelines share h exactly when they are configured the same.
