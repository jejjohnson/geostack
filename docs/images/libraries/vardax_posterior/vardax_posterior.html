vardax — four ways to build the posterior covariance
Every analysis can hand back a Posterior whose covariance Σx∣y is a lazy operator. The families differ in how a mat-vec with it is computed, what it costs and when it is right. Each sketch is a two-dimensional state: grey is the prior or the cost, colour the posterior Σx∣y as a two-standard-deviation ellipse.
