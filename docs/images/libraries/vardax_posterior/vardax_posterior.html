vardax — four ways to build the posterior covariance
Every analysis can hand back a Posterior whose covariance \boldsymbol{\Sigma}_{x \mid y} is a lazy operator. The families differ in how a mat-vec with it is computed, what it costs and when it is right. Each sketch is a two-dimensional state: grey is the prior or the cost, colour the posterior \boldsymbol{\Sigma}_{x \mid y} as a two-standard-deviation ellipse.

LinearParameterization or ReducedBasisFourDVar(basis=...): the precision is built for the coefficients, \boldsymbol{\Sigma}_{x \mid y} = \boldsymbol{\Phi} \boldsymbol{\Sigma}_{z \mid y} \boldsymbol{\Phi}^\top, and samples factor only the small \boldsymbol{\Sigma}_{z \mid y}; any other parameterization raises ValueError
the weak constraint
WeakFourDVar returns the \mathbf{x}_0 block of \boldsymbol{\Lambda}_{w \mid y}^{-1} over \mathbf{w} = (\mathbf{x}_0, \boldsymbol{\eta}_1, \ldots, \boldsymbol{\eta}_T): the Kalman-smoother covariance of \mathbf{x}_0 in the linear-Gaussian case
