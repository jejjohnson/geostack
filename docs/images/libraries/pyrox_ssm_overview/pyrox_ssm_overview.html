pyrox-ssm — one recursion, many models
A kernel for time is the covariance of a linear SDE, so the same prior is a Markov chain on a small state and a Kalman filter scores it in one pass. Every model in the package is that recursion over some state, written as a NumPyro model.

{o_k = 0 \ \Rightarrow \ \mathbf{m}_k = \mathbf{m}_k^-, \ \mathbf{P}_k = \mathbf{P}_k^-}
