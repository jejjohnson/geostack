pyrox-lgm — one latent field, many components
A trend, a spatial effect and a random intercept are each sparse in their precision, so their sum is a latent Gaussian model with one sparse precision. inla() integrates the field out by nested Laplace approximations, and the same components also sample inside NumPyro.
