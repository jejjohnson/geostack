vardax — four ways to differentiate a rollout
Each computes the gradient \nabla_{\mathbf{x}_0} \mathcal{J} of a 4D-Var cost through the rollout. What changes is which states of the rollout are kept for the backward pass, so what it costs and when it is right.

forward_adjoint=
vardax hands the choice to forward.with_adjoint, which a diffrax-backed forward passes to diffeqsolve. For any per-step forward, checkpoint=True (or a block length k) wraps each step in jax.checkpoint through integrix instead; the gradient is unchanged.
minimiser_adjoint=
A separate slot differentiates the inner minimisation, not the rollout: optx.ImplicitAdjoint by default, or argminax's KStep and OneStep, compared in argminax's adjoints figure.
