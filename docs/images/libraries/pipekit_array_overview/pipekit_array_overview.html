pipekit-array — one rule, by dim name, on any backend
Write a step once against the Array API, by dim name: it runs on the library that holds the data, on whatever carrier holds the names, and as an operator in a pipekit pipeline.
supplywhat you bring
data on any backend
NumPy, JAX or dask arrays through the Array API, and PyTorch for the plain-array functions
a carrier with dim names
DimArray, an xr.DataArray, or any carrier whose library registers an adapter
the dims to consume
by name: "time", ("y", "x"), never axis=1
or your own function
a function f of plain arrays, with a signature such as "(c)->()"
one ruleby dim name
\mathbf{y}_\ell = f\left(\mathbf{x}^{(1)}_\ell, \ldots, \mathbf{x}^{(N_\text{in})}_\ell\right)
the loop dims: every index the operation does not consume, matched by name
\ell \in \text{loop dims}
at each \ell, input k over its core dims \mathcal{C}_k
\mathbf{x}^{(k)}_\ell \in \mathbb{R}^{N_{\mathcal{C}_k}}
No index is a position, so transposing an input changes nothing; f takes its functions from its inputs' namespace.
