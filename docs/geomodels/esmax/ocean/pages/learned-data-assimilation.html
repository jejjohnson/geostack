Learned data assimilation: what can be learned in the analysis

The taxonomy page took the model apart. This page takes the assimilation apart: the objective, its gradient, the solver, the output, and whether the answer is computed per window or learned across windows. Eleven ways to learn one of those pieces, on the same Gulf Stream QG example and the same 10-day window of SSH maps.

TL;DR

One analysis operator, eleven insides

  • Every type is box 2's operator: maps, masks, errors, background, covariates and forcing in; a state window and its uncertainty out. What changes is the inside, the training data it needs, and whether the output is a point, an ensemble or a density.
  • The training signal matters more than the network. Simulated truth (OSSE) learns the QG model's ocean; the ELBO and held-out observations learn the real one but never see unobserved scales.
  • Mean, mode or sample. 4D-Var returns a mode, an MSE-trained network a mean, VI a density. Benchmarks must compare the same statistic.
  • Teal types fail loudly: the classical cost or solver is still there to check the answer. Amber types fail silently: an unusual window gets a confident wrong field. Scoring any output with the classical 𝒥 and its innovations turns most silent failures into loud ones.

The master equation

Weak-constraint 4D-Var over one window. With \(p(\vect{x} \mid \vect{y}) \propto \exp(-\mathcal{J}(\vect{x}))\), every type on this page edits this cost, its gradient, its solver, or replaces all three:

\[ \mathcal{J}(\vect{x}_{0:T}; \gvect{\theta}) = \underbrace{\frac{1}{2} \Vert \vect{x}_0 - \gvect{\mu}_x \Vert^2_{\gmat{\Sigma}_x^{-1}}}_{\text{background}} + \underbrace{\frac{1}{2} \sum_{k=1}^{T} \Vert \vect{x}_k - f(\vect{x}_{k-1}, \vect{u}_k; \gvect{\theta}) \Vert^2_{\gmat{\Sigma}_\eta^{-1}}}_{\text{dynamics}} + \underbrace{\frac{1}{2} \sum_{k=1}^{T} \Vert \vect{m}_k \odot (\vect{y}_k - \vect{x}_k) \Vert^2_{\gmat{\Sigma}_{\varepsilon,k}^{-1}}}_{\text{observations}} . \]

The classical solver iterates \(\vect{x}^{(i+1)} = \vect{x}^{(i)} - \gamma \mat{P} \nabla_{\vect{x}} \mathcal{J}(\vect{x}^{(i)})\) from \(\vect{x}^{(0)}\), with step size \(\gamma\), \(N \approx 50\)–\(100\) and \(\mat{P}\) built from \(\gmat{\Sigma}_x^{1/2}\). In code, the cost, the solver and the variational objective are three short functions. qg_day and QGParams are the ones defined on the taxonomy page:

import einx
import equinox as eqx
import finitevolx as fvx
import gaussx as gx
import jax
import jax.numpy as jnp
import lineax as lx
from jaxtyping import Array, Bool, Float, PRNGKeyArray

# Shapes: T = 10 maps (time); Z = T + 1 = 11 states x₀ … x₁₀ (day);
#         H, W = 130 × 130 grid with ghost ring (height, width);
#         N = H·W (cell); F = Z·N (flat); K = 16 (rank); S = 8 samples (member)

Op = lx.AbstractLinearOperator


class Window(eqx.Module):
    """One window: maps y, masks m, errors σ_ε², background μ_x, Σ_x, diagonal Σ_η."""

    maps: Float[Array, "time height width"]
    masks: Bool[Array, "time height width"]
    obs_var: Float[Array, "time height width"]
    model_err_var: Float[Array, "time height width"]
    background: Float[Array, "height width"]
    covariates: Float[Array, "variable height width"]
    forcing: Float[Array, "time height width"]
    prior_cov: Op
    grid: fvx.CartesianGrid2D


def weak_4dvar_cost(
    states: Float[Array, "day height width"],
    window: Window,
    params: QGParams,
) -> Float[Array, ""]:
    # --- background ---
    # δ₀ = x₀ − μ_x
    initial_departure = states[0] - window.background  # (H, W)
    departure_flat = einx.rearrange(                  # (H, W) → (N,)
        "height width -> (height width)", initial_departure
    )
    # today (gaussx)
    # δ₀ᵀ Σ_x⁻¹ δ₀
    background_quad = gx.quadratic_form(window.prior_cov, departure_flat)  # → ()
    # 𝒥_x = ½ δ₀ᵀ Σ_x⁻¹ δ₀
    background_cost = 0.5 * background_quad           # → ()

    # --- dynamics, all days at once ---
    previous = states[:-1]                            # (Z, Z) → (T, H, W)
    current = states[1:]                              # (Z, Z) → (T, H, W)
    batched_day = jax.vmap(qg_day, in_axes=(0, None, 0, None, None))
    # user (qg_day, taxonomy page)
    # f(x_{k−1}, u_k; θ) for every k, in parallel
    forecasts = batched_day(                          # (T, H, W) → (T, H, W)
        previous, window.covariates, window.forcing, params, window.grid
    )
    # η_k = x_k − f(x_{k−1}, u_k; θ)
    model_error = current - forecasts                 # (T, H, W)
    # η_k²
    squared_error = model_error**2                    # (T, H, W)
    # η_k² / σ_η²  (diagonal Σ_η)
    weighted_error = squared_error / window.model_err_var  # (T, H, W)
    # ∑_k η_kᵀ Σ_η⁻¹ η_k
    model_sum = einx.sum("time height width ->", weighted_error)  # → ()
    # 𝒥_η = ½ ∑_k ‖η_k‖²_{Σ_η⁻¹}
    model_cost = 0.5 * model_sum                      # → ()

    # --- observations ---
    # y_k − x_k
    misfit = window.maps - current                    # (T, H, W)
    # r_k = m_k ⊙ (y_k − x_k)
    residual = jnp.where(window.masks, misfit, 0.0)   # (T, H, W)
    # r_k²
    squared_residual = residual**2                    # (T, H, W)
    # r_k² / σ_{ε,k}²
    weighted_residual = squared_residual / window.obs_var  # (T, H, W)
    # ∑_k r_kᵀ Σ_{ε,k}⁻¹ r_k
    obs_sum = einx.sum("time height width ->", weighted_residual)  # → ()
    # 𝒥_ε = ½ ∑_k ‖m_k ⊙ (y_k − x_k)‖²_{Σ_{ε,k}⁻¹}
    obs_cost = 0.5 * obs_sum                          # → ()

    # 𝒥 = 𝒥_x + 𝒥_η + 𝒥_ε
    total_cost = background_cost + model_cost + obs_cost  # → ()
    return total_cost


def analyse(
    window: Window,
    params: QGParams,
    initial_states: Float[Array, "day height width"],
    *,
    step_size: float = 0.1,
    n_iterations: int = 100,
) -> Float[Array, "day height width"]:
    cost_gradient = jax.grad(weak_4dvar_cost)

    def iterate(states, _):
        # ∇_x 𝒥(x⁽ⁱ⁾), by reverse mode
        gradient = cost_gradient(states, window, params)  # → (Z, H, W)
        # user
        # d⁽ⁱ⁾ = P ∇_x 𝒥(x⁽ⁱ⁾)
        direction = precondition(gradient, window)    # (Z, H, W)
        # γ d⁽ⁱ⁾
        update = step_size * direction                # (Z, H, W)
        # x⁽ⁱ⁺¹⁾ = x⁽ⁱ⁾ − γ P ∇_x 𝒥(x⁽ⁱ⁾)
        states = states - update                      # (Z, H, W)
        return states, None

    analysis, _ = jax.lax.scan(                       # (Z, H, W) → (Z, H, W)
        iterate, initial_states, None, length=n_iterations
    )
    return analysis


class LowRankGaussian(eqx.Module):
    """q(x) = 𝒩(μ_q, L_q L_qᵀ + D_q) over a whole window, flattened."""

    mean: Float[Array, "flat"]
    factor: Float[Array, "flat rank"]
    log_diag: Float[Array, "flat"]


def neg_elbo(
    posterior: LowRankGaussian,
    window: Window,
    params: QGParams,
    *,
    n_samples: int = 8,
    key: PRNGKeyArray,
) -> Float[Array, ""]:
    height, width = window.background.shape

    # --- variational density ---
    # D_q = diag(exp(log d))
    diag = jnp.exp(posterior.log_diag)                # (F,) → (F,)
    # today (gaussx)
    # Σ_q = L_q L_qᵀ + D_q
    covariance = gx.low_rank_plus_diag(diag, posterior.factor)  # (F, F) PSD op

    # --- samples ---
    # today (gaussx)
    # x⁽ᵉ⁾ = μ_q + Σ_q^{1/2} ξ,  ξ ~ 𝒩(0, I)
    samples_flat = gx.sample_mvn(                     # → (S, F)
        posterior.mean, covariance, key=key, num_samples=n_samples
    )
    samples = einx.rearrange(                         # (S, F) → (S, Z, H, W)
        "member (day height width) -> member day height width",
        samples_flat,
        height=height,
        width=width,
    )

    # --- expected cost and entropy ---
    batched_cost = jax.vmap(weak_4dvar_cost, in_axes=(0, None, None))
    # 𝒥(x⁽ᵉ⁾) for each sample
    sample_costs = batched_cost(samples, window, params)  # → (S,)
    # 𝔼_q[𝒥] ≈ (1/S) ∑_e 𝒥(x⁽ᵉ⁾)
    expected_cost = einx.mean("member ->", sample_costs)  # (S,) → ()
    # today (gaussx)
    # ℍ[q] = ½ (N (1 + log 2π) + log det Σ_q)
    entropy = gx.gaussian_entropy(covariance)         # → ()

    # ℒ_ELBO = −ELBO = 𝔼_q[𝒥(x)] − ℍ[q],  since p(x | y) ∝ exp(−𝒥(x))
    loss = expected_cost - entropy                    # → ()
    return loss

Markers: today ships on main (checked 24 Oct 2026: finitevolX 831c69f, gaussx eeda235, somax 9cb19b3); today* ships, arguments sketched; user is defined on these pages; not pinned is a library whose API was not checked. Shape column letters are defined in the header.

No Gaussian variational family ships in gaussx or vardax, so LowRankGaussian is page-defined; gaussx supplies its covariance, samples and entropy.

The simulation gap and the resolution gap

OSSE-trained types learn the climate of the QG model: its eddy sizes, its energy, its errors. Observation-trained types learn the real ocean, but gridded SSH maps resolve little below roughly 100 km, so held-out-pixel losses cannot teach anything finer. The practical combination is to pretrain on OSSEs for the small scales and fine-tune with the ELBO or held-out observations for the large ones.

The eleven types

Each card gives the equation, the operator signature with what is learned and what it trains on, and attribute rows. The training signal is a row, as on the taxonomy page.

A1

Learned hyperparameters

replaces: hand-tuned α

Keep everything, and fit the numbers that shape \(\gmat{\Sigma}_x\), \(\gmat{\Sigma}_\eta\), \(\gmat{\Sigma}_\varepsilon\), localisation and inflation by maximising the evidence over many real windows \(w\):

\[ \gvect{\alpha}^\star = \mathrm{argmax}_{\gvect{\alpha}} \sum_{w} \log p(\vect{y}^{(w)} \mid \gvect{\alpha}) \] \[ \log p(\vect{y} \mid \gvect{\alpha}) \approx -\mathcal{J}(\hat{\vect{x}}; \gvect{\alpha}) - \frac{1}{2} \log \det \nabla^2_{\vect{x}} \mathcal{J}(\hat{\vect{x}}; \gvect{\alpha}) + \text{const}. \]

The right-hand side is the Laplace approximation at the analysis \(\hat{\vect{x}}\). The cheaper alternative is to match the innovation statistics of the state-estimation page.

A2

Learned prior

replaces: the background and dynamics terms

The observation term stays; the regulariser becomes learned. Three forms, from least to most physical:

\[ \mathcal{J}_\text{learned}(\vect{x}) = \frac{1}{2} \sum_k \Vert \vect{m}_k \odot (\vect{y}_k - \vect{x}_k) \Vert^2_{\gmat{\Sigma}_{\varepsilon,k}^{-1}} + \beta \mathcal{R}(\vect{x}), \] \[ \mathcal{R}(\vect{x}) \in \left\{ -\log p(\vect{x}; \gvect{\theta}_\text{DA}), \Vert \vect{x} - g_\text{proj}(\vect{x}; \gvect{\theta}_\text{DA}) \Vert^2, \frac{1}{2} \sum_k \Vert \vect{x}_k - f(\vect{x}_{k-1}; \gvect{\theta}_\text{emu}) \Vert^2_{\gmat{\Sigma}_\eta^{-1}} \right\}. \]

The first is a density (a flow or an energy model on windows). The second is a projection: \(g_\text{proj}\) maps a window to the nearest plausible one, as in 4DVarNet. The third is weak-constraint 4D-Var with any hybrid model from the taxonomy page as \(f(\cdot; \gvect{\theta}_\text{emu})\).

The dynamical form is the important one: it keeps physics in the prior and makes every model on the taxonomy page a candidate. The projection form is expressive but carries no physics, and it is not a normalised density, so it cannot be sampled.

A3

Approximate gradient

replaces: the adjoint

Keep the cost and the solver; compute \(\nabla_{\vect{x}} \mathcal{J}\) more cheaply. With \(\mat{F}_k = \mat{J}_f(\vect{x}_{k-1})\) the tangent-linear model and \(\tilde{\mat{X}}_k \in \mathbb{R}^{D_x \times N_{\mathcal{E}}}\) ensemble anomalies:

\[ \underbrace{\mat{F}_k^\top \to \mat{J}_f(\vect{x}_{k-1}; \gvect{\theta}_\text{emu})^\top}_{\text{emulator adjoint}} \] \[ \underbrace{\vect{x}_0 = \gvect{\mu}_x + \tilde{\mat{X}}_0 \vect{z}_\text{ens}, \text{ } \mat{F}_{k \leftarrow 0} \tilde{\mat{X}}_0 \approx \tilde{\mat{X}}_k}_{\text{ensemble-variational, no adjoint}} \] \[ \underbrace{\nabla_{\vect{x}} \mathcal{J} \approx g_\text{grad}(\vect{x}, \vect{y}; \gvect{\theta}_\text{DA})}_{\text{learned gradient}} . \]

Here \(\vect{z}_\text{ens} \in \mathbb{R}^{N_{\mathcal{E}}}\) has one entry per ensemble member and \(\mat{F}_{k \leftarrow 0}\) maps an initial perturbation to day \(k\).

A4

Learned solver (unrolled)

replaces: the optimiser

A network decides each update from the gradient and an internal memory \(\vect{z}_\text{mem}\). The loop is unrolled for a fixed \(N \approx 10\) iterations and trained end to end, usually together with a learned prior (A2):

\[ \begin{aligned} \vect{x}^{(i+1)} &= \vect{x}^{(i)} - g_\text{step}\left(\nabla_{\vect{x}} \mathcal{J}_\text{learned}(\vect{x}^{(i)}), \vect{z}_\text{mem}^{(i)}; \gvect{\theta}_\text{DA}\right),\\ \vect{z}_\text{mem}^{(i+1)} &= g_\text{mem}\left(\nabla_{\vect{x}} \mathcal{J}_\text{learned}(\vect{x}^{(i)}), \vect{z}_\text{mem}^{(i)}; \gvect{\theta}_\text{DA}\right),\\ \gvect{\theta}_\text{DA}^\star &= \mathrm{argmin}_{\gvect{\theta}_\text{DA}} \mathcal{L}_\text{MSE}(\gvect{\theta}_\text{DA}), \text{ } \mathcal{L}_\text{MSE}(\gvect{\theta}_\text{DA}) = \mathbb{E}_{(\vect{x}, \vect{y})} \Vert \vect{x} - \vect{x}^{(N)}(\vect{y}; \gvect{\theta}_\text{DA}) \Vert^2 . \end{aligned} \]

A5

A6

Amortised point analysis

replaces: the whole solve

A8

Per-window variational inference

replaces: the point estimate

Fit a Gaussian to each window's posterior directly. With \(\gvect{\xi} \sim \mathcal{N}(\vect{0}, \mat{I})\), samples are reparameterised, and the ELBO uses the classical cost because \(p(\vect{x} \mid \vect{y}) \propto \exp(-\mathcal{J}(\vect{x}))\):

\[ \vect{x} = \gvect{\mu}_q + \mat{L}_q \gvect{\xi}_1 + \mat{D}_q^{1/2} \gvect{\xi}_2 \] \[ \min_{\gvect{\mu}_q, \mat{L}_q, \mat{D}_q} \mathcal{L}_\text{ELBO} = \mathbb{E}_{q}\left[\mathcal{J}(\vect{x})\right] - \mathbb{H}[q]. \]

As the rank grows, \(\gvect{\mu}_q\) approaches the posterior mean and \(\mat{L}_q \mat{L}_q^\top + \mat{D}_q\) the posterior covariance. With one sample at \(\gvect{\xi} = \vect{0}\), it collapses to 4D-Var.

What the structure implies

Score every output with the classical cost

Whatever produced \(\hat{\vect{x}}\), computing \(\mathcal{J}(\hat{\vect{x}})\), \(2 \mathcal{J}^\star / D_y\) and the innovations costs one model run. It is the cheapest guard against silent failure, and it makes the box-2 diagnostics of the state-estimation page apply to every learned type.

A learned cost is not a posterior

Once a cost is trained end to end for MSE (A2 with A4), its minimiser is no longer the point of interest and \(\exp(-\mathcal{J}_\text{learned})\) is not a calibrated density. Uncertainty then has to come from somewhere else: an ensemble of solvers, a VI head, or A8 run around the output.

The safe ladder

A1 → A5 → A8 → A9 keeps the classical machinery in charge at every step and adds learning only where it pays: tuning, speed, uncertainty, then amortisation with refinement. A4, A6 and A7 jump straight to amortisation and give up the checks; they are worth it when per-window cost is the binding constraint and the training distribution covers the windows you will see.

Learning the model needs the analysis

A11 is the only way to train a correction-type hybrid from observations alone. It inherits every weakness of its E-step, and it can let the model absorb analysis errors. Fix α first (A1), and keep the model's learned part structural (T1, T2, T4) so it cannot explain everything.
